# הרמת הכלי על שרת, חינם

המטרה: לפתוח את הכלי מהנייד ומכל מחשב, בלי שהמק הראשי יהיה דלוק.

הכל כאן חינם לתמיד. צריך כרטיס אשראי פעם אחת לאימות זהות מול Oracle,
והוא לא מחויב.

---

## מה הולך לקרות

1. פותחים שרת חינמי ב-Oracle Cloud
2. מצמידים לו כתובת אינטרנט חינמית
3. מריצים סקריפט אחד שמתקין את הכל
4. מוסיפים את הכלי למסך הבית של הטלפון

בערך 40 דקות, רובן המתנה.

---

## 1. שרת ב-Oracle Cloud

נרשמים ב-`cloud.oracle.com` ובוחרים "Start for free".

בבחירת האזור, עדיף אזור קרוב כמו Frankfurt או Amsterdam. **האזור נקבע
פעם אחת ואי אפשר לשנות אותו אחר כך**, אז כדאי לעצור ולבחור בכוונה.

אחרי ההרשמה, יוצרים מכונה:

- Compute ואז Instances ואז Create instance
- Image: **Ubuntu 24.04**
- Shape: לוחצים Change shape ובוחרים **Ampere** ואז `VM.Standard.A1.Flex`
- **4 OCPU ו-24GB** אם מוצע, אחרת **2 OCPU ו-12GB**
- Boot volume: מגדילים ל-**100GB** לפחות, יש 200 חינם
- מורידים את קובץ המפתח (`.key`) ושומרים אותו. **הוא לא יוצע שוב.**

### אם כתוב Out of capacity

זה הדבר הנפוץ ביותר ב-Oracle, ולא עשית שום דבר לא נכון. המלאי של
מעבדי ARM החינמיים נגמר באזורים פופולריים.

שלוש דרכים, לפי הסדר:

1. לנסות Availability Domain אחר באותו אזור (AD-1, AD-2, AD-3)
2. לנסות שוב בשעות אחרות. זה משתחרר
3. לשדרג את החשבון ל-Pay As You Go. **זה לא עולה כסף** על המשאבים
   שמוגדרים Always Free, אבל זה מקפיץ אותך בתור המלאי משמעותית

### פתיחת הפורטים במסך הניהול

במכונה, לוחצים על ה-Subnet ואז על ה-Security List, ומוסיפים
Ingress Rules:

| Source    | Protocol | Destination Port |
|-----------|----------|------------------|
| 0.0.0.0/0 | TCP      | 80               |
| 0.0.0.0/0 | TCP      | 443              |

זה הכרחי, אבל **לא מספיק**. יש חומת אש שנייה בתוך השרת עצמו,
והסקריפט בשלב 3 מטפל בה. זו הנקודה שתוקעת כמעט כל אחד.

## 2. כתובת אינטרנט חינמית

הכלי צריך דומיין כדי להוציא תעודת HTTPS. בלי HTTPS הדפדפן לא יאפשר
להתקין אותו כאפליקציה, והסיסמה תיסע גלויה ברשת.

החינמי והפשוט ביותר הוא **DuckDNS**:

1. נכנסים ל-`duckdns.org` ומתחברים עם חשבון גוגל
2. בוחרים שם, למשל `netanel-captions`
3. בשדה `current ip` מדביקים את ה-Public IP של השרת ולוחצים update

הכתובת שלך תהיה `netanel-captions.duckdns.org`.

אם יש לך דומיין משלך, אפשר פשוט להפנות רשומת A לכתובת ה-IP.

## 3. התקנה

מתחברים לשרת מהטרמינל במק:

```bash
chmod 600 ~/Downloads/ssh-key-*.key
ssh -i ~/Downloads/ssh-key-*.key ubuntu@<ה-IP-של-השרת>
```

ועל השרת מריצים:

```bash
curl -fsSL https://raw.githubusercontent.com/netfire222/hebrew-captions/main/deploy/setup.sh -o setup.sh
bash setup.sh
```

הסקריפט שואל שתי שאלות, הדומיין והסיסמה, ואז עושה הכל לבד: מתקין
דוקר, פותח את חומת האש הפנימית, מוריד את הקוד, בונה ומפעיל.

הבנייה הראשונה לוקחת כמה דקות כי היא מורידה את מודל התמלול.

בסוף תקבל כתובת. זהו.

**אל תחזיק שם את העותק היחיד של שום דבר.** הסרטונים הגולמיים נשארים
אצלך, והייצואים כדאי להוריד למחשב. הכלי על המק ממשיך לעבוד בדיוק
כמו קודם, והשרת הוא תוספת ולא תחליף.

## תחזוקה

```bash
cd ~/hebrew-captions

docker compose logs -f app                      # מה קורה
docker compose restart app                      # הפעלה מחדש
git pull && docker compose up -d --build        # עדכון לגרסה חדשה
docker system prune -af                         # פינוי מקום
```

להחלפת סיסמה: עורכים את `APP_PASSWORD` בקובץ `.env` ואז
`docker compose up -d`. כל המכשירים יתנתקו ויצטרכו להיכנס מחדש.

## אם מסך הסיסמה חוזר שוב ושוב

הכלי יגיד לך את זה במפורש: "הסיסמה התקבלה אבל הדפדפן לא שמר את
ההתחברות". המשמעות היא שנכנסת דרך `http` ולא `https`, ועוגיית
ההתחברות מסורבת בכוונה כשאין הצפנה.

הפתרון הוא להיכנס דרך הדומיין עם `https`, לא דרך כתובת ה-IP.

אם אתה מריץ ברשת מקומית בלבד, בלי דומיין ובלי תעודה, אפשר להוסיף
ל-`.env` את השורה `HEBCAP_COOKIE_SECURE=0`. **רק ברשת פרטית.**
באינטרנט הפתוח זה אומר שהסיסמה נוסעת גלויה.
