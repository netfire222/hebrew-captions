# כתוביות בעברית

כלי מקומי להוספת כתוביות בעברית לסרטונים. תמלול אוטומטי או הדבקת תסריט,
תצוגה חיה בדפדפן, וייצוא עם כתוביות צרובות.

הכל רץ על המחשב שלך. בלי מנוי, בלי ענן, בלי להעלות את הסרטונים שלך לשום מקום.

## למה זה קיים

כלי הכתוביות הגנריים שוברים עברית בשלוש נקודות: סדר המילים מתהפך כשיש מספרים
או אנגלית בתוך המשפט, הם לא מכירים מונחי AI ושמות מותגים, והפונטים העבריים
שלהם מוגבלים. הכלי הזה מטפל בשלושתן.

הוא נבנה בערב אחד עם קלוד קוד, בלי לכתוב שורת קוד ביד. זו גם הנקודה: אם יש לך
כלי שאתה משלם עליו כל חודש ועושה בשבילך דבר אחד ספציפי, אתה כנראה יכול לבנות
אותו לבד.

## התקנה והרצה

### במאק, הדרך הקצרה

לחיצה כפולה על `start.command`. בפעם הראשונה הוא מתקין מה שצריך ואז פותח את
הכלי בדפדפן. אחר כך כל פתיחה מיידית.

לא צריך Homebrew ולא צריך סיסמת מנהל. הכל דרך pip בתוך סביבה מבודדת בתיקיית
הפרויקט, ושום דבר לא נוגע במערכת.

אם מאק חוסם בפעם הראשונה כי הקובץ לא חתום: קליק ימני, פתיחה, ואז "פתח". פעם אחת.

### מהטרמינל, בכל מערכת

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install flask Pillow imageio-ffmpeg faster-whisper
python3 app.py
```

ואז נכנסים ל-http://localhost:8769

| חבילה | תפקיד |
|---|---|
| `flask` | השרת המקומי |
| `Pillow` | רינדור הכתוביות |
| `imageio-ffmpeg` | מביא ffmpeg סטטי. אם יש ffmpeg במערכת הכלי יעדיף אותו |
| `faster-whisper` | התמלול |

## איך עובדים

1. מעלים סרטון
2. בוחרים מצב טקסט: תמלול אוטומטי, או הדבקת התסריט המדויק
3. בוחרים שפת דובר: עברית, אנגלית או זיהוי אוטומטי
4. בוחרים פריסט כנקודת פתיחה
5. מעצבים: פונט, גודל, מיקום, צבעים, קונטור והצללה
6. בודקים בתצוגה החיה
7. מייצאים

### מתי להשתמש בהדבקת טקסט

whisper בעברית טועה בשמות מותגים ובמונחי AI. "קלוד קוד" יוצא "קלאוד קוד",
ופקודות עם לוכסן נעלמות. כשיש לך את התסריט ממילא, מצב ההדבקה נותן טקסט מדויק
ותזמון אמיתי שנמדד מהאודיו.

## מה יש בפנים

**שישה פריסטים** כנקודת פתיחה: פופ צהוב, בלוק כהה, צבעי מותג, מילה אחת,
קרנטינה הוק, לבן נקי.

**עיצוב מלא**: כל הפונטים שבתיקייה עם תצוגה מקדימה, גודל כאחוז מגובה הפריים,
מיקום בסרגלים או בגרירה ישירה על הווידאו, בוררי צבע מלאים לטקסט ולמילה
הנוכחית, קונטור והצללה עם צבע ועוצמה.

**שמירת ערכות**: אחרי שעיצבת, שומרים בשם ומקבלים כרטיס לחיץ. נשמר לקובץ
מקומי ושורד הפעלה מחדש.

**הסרת מילות מילוי**: הכלי מוריד מהכתוביות "אה", "אמ", "כאילו", "יעני".
הרשימה שמרנית בכוונה. זה מנקה את הטקסט בלבד, האודיו לא נחתך.

**הדגשה אוטומטית**: מספרים, אחוזים, מונחים באנגלית ופקודות עם לוכסן מקבלים
את צבע ההדגשה אוטומטית. אלה בדרך כלל המילים שנושאות את הערך.

## ההערה הטכנית שבגללה זה עובד

הכלי לא נותן לאלגוריתם הדו-כיווני לסדר שורה שלמה. הוא מפרק למילים ומניח אותן
ידנית מימין לשמאל. זה מה שמאפשר לצבוע ולהגדיל מילה בודדת, וזה גם מה שמונע את
הבאג הקלאסי שבו "10 פקודות" הופך ל"פקודות 10".

בנוסף, ה-wheel של Pillow ל-macOS לא כולל RAQM, גם בגרסה 11 וגם ב-12. במקום
לשלוח אותך להתקין ספריות מערכת, יש כאן מסלול שמסדר כל טוקן עברי ויזואלית
בעצמו. עברית, בניגוד לערבית, לא דורשת עיצוב הקשרי, ולכן זה תקף.

## להתאים את זה לעצמך

הדרך המהירה: לפתוח את התיקייה בקלוד קוד ולבקש. יש בפרויקט קובץ `CLAUDE.md`
שמסביר את הארכיטקטורה, את המוסכמות ואת המלכודות, כך שהוא כבר מכיר את הקוד
ואפשר לבקש ממנו שינויים ישירות. למשל:

- "תוסיף פריסט בצבעים של המותג שלי"
- "תעשה שהכתוביות יופיעו מילה מילה במקום בקבוצות"
- "תוסיף תמיכה בערבית"
- "תוסיף כפתור שמייצא גם קובץ SRT"

הידני: `styles.py` לפריסטים ולפונטים, `caption_render.py` למנוע הרינדור,
`ui.html` לממשק. הפירוט המלא ב-`CLAUDE.md`.

## פתרון בעיות

**התמלול איטי.** ברירת המחדל היא המודל הגדול. למהירות:
`HEBCAP_MODEL=medium python3 app.py`. במצב הדבקת טקסט זה כמעט לא משנה, כי
הטקסט מגיע ממך.

**פונט לא נטען.** הפונטים מצורפים ב-`fonts/`. אם התיקייה נמחקה, שחזר אותה.

**ffmpeg.** לא צריך להתקין. אם בכל זאת יש לך אחד במערכת, הכלי יעדיף אותו.

**השרת רץ אבל אין פקדים חדשים.** סימן שהוא עלה עם קוד ישן. סגור את הטרמינל
והרץ מחדש. יש באנר אזהרה שמזהה את זה לבד.

## English

A local Hebrew subtitle tool. Auto transcription or pasted script, live browser
preview, burned in captions on export. Runs entirely on your machine, no cloud
and no subscription.

Generic caption tools break Hebrew when a line mixes numbers or Latin words:
the word order flips. This tool lays out words manually right to left instead
of handing the whole line to the bidi algorithm, so "10 פקודות" stays
"10 פקודות" and `/fork` does not render as `fork/`.

Quick start: `python3 -m venv .venv && source .venv/bin/activate &&
pip install flask Pillow imageio-ffmpeg faster-whisper && python3 app.py`,
then open http://localhost:8769

Open the folder in Claude Code to customise it. `CLAUDE.md` documents the
architecture, the RTL invariants and the known pitfalls.

Code is MIT. Bundled fonts are SIL OFL 1.1, see `fonts/`.
